# SPACEWAR

宇宙戦闘機のコクピットから、飛来する敵を撃ち落とす 3D シューティングゲームです。
iPhone / iPad の Safari で、URL を開くだけで遊べます（インストール不要）。

## 遊び方

| 操作 | 内容 |
| --- | --- |
| 画面の左側をなぞる | 上下左右に移動（指を置いた場所にスティックが出ます） |
| FIRE（右下） | レーザー射撃。押し続けると連射。撃ち続けると砲身が過熱して一時的に撃てなくなります |
| MSL | 敵を照準に重ねてロックオン（赤い枠）してから押すと、追尾ミサイルを発射 |
| 右上の II | 一時停止 |

- 敵は波（ウェーブ）ごとに押し寄せ、ウェーブが進むほど数・速さ・攻撃が増えます
- 3 ウェーブごとに大型の重爆撃機が現れ、誘導ミサイルを撃ってきます。ミサイルは撃ち落とすか避けてください
- シールドは攻撃を受けない時間が続くと回復します。船体（HULL）が 0 になると撃墜です
- ウェーブを越えると、ボーナス点・船体の修理・ミサイルの補給があります
- 続けて撃墜すると得点の倍率が上がります（最大 3 倍）
- 横画面専用です。「ホーム画面に追加」すると全画面で起動できます

タイトル画面で、画質（自動／高／中／低）、操縦方法（スティック／傾き）、上下反転、効果音を切り替えられます。

## 公開のしかた（GitHub Pages）

1. GitHub のこのリポジトリで **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、**Branch** を `main` / `/ (root)` にして Save
3. 数分後に表示される URL（`https://<ユーザー名>.github.io/game-spacewar/`）を iPhone / iPad の Safari で開く

## 仕組み

- 3D 描画は [three.js](https://threejs.org/)（CDN から読み込み、ビルド作業なし）
- 機体・星雲・惑星・効果音はすべてプログラムで生成しており、外部の画像や音声ファイルは使っていません
- HDR 描画、ブルーム、ACES トーンマッピングで光の表現を作り、端末の処理速度に合わせて描画解像度を自動で調整します

| ファイル | 役割 |
| --- | --- |
| `src/main.js` | 起動、ゲームループ、画面の切り替え |
| `src/renderer.js` | 描画、ポストエフェクト、画質の自動調整 |
| `src/space.js` | 星雲・星・惑星・太陽・宇宙塵・小惑星 |
| `src/cockpit.js` | コクピット、計器画面、キャノピーガラス |
| `src/player.js` | 自機の移動・シールド・船体 |
| `src/enemies.js` | 敵機の形と動き |
| `src/weapons.js` | レーザー、ロックオン、ミサイル |
| `src/effects.js` | 爆発・火花・破片 |
| `src/waves.js` | ウェーブ構成と難易度 |
| `src/input.js` | タッチ操作・傾き操作 |
| `src/audio.js` | 効果音（Web Audio で合成） |
| `src/hud.js` | 照準・ゲージ・目標表示 |

パソコンのブラウザでも、矢印キー（WASD）で移動、スペースで射撃、M でミサイルとして動作確認できます。
URL の末尾に `?fps` を付けると、フレームレートと描画解像度を表示します。
